# mod_leafr (Leafr PDF Flipbook Reader)

Moodle Activity Plugin for a modern PDF Flipbook experience.

## Description
Leafr is a Moodle Activity Plugin that allows users to read PDF documents in a beautiful, interactive flipbook format. It uses PDF.js for rendering and StPageFlip for the flipping animation.

## Features
- Modern PDF rendering with PDF.js
- Smooth page-flipping animation
- Mobile-friendly and responsive
- Progress tracking and completion support
- Bookmark support (Pro only)

## Requirements
- Moodle 4.1 LTS or higher
- PHP 8.1 or higher

## Installation
Standard Moodle plugin installation. Upload the ZIP file or clone this repository into `/mod/leafr`.
